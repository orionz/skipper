# Sparkle Journal

A one-page nightly symptom journal. Installs as a PWA, works offline, stores everything
in the browser's localStorage on the device — nothing is uploaded anywhere.

Three screens:

- **Today** — the 60-second daily log. Autosaves on every tap; use `‹ ›` to backfill a missed day.
- **Attack** — the per-attack form. Tier A discriminators are in the highlighted card.
  A half-filled form is kept as a draft if the app is closed mid-attack.
- **Log** — every entry, tap to edit, plus CSV/JSON export.

## Export

`Daily log → CSV` and `Attack log → CSV`. Every checkbox becomes its own `0`/`1` column so a
spreadsheet can sort and filter on it — `prior24_alcohol`, `skin_flushing`, `helped_gabapentin`
and so on. On a phone it opens the share sheet; on a computer it downloads.

`Full backup → JSON` is the round-trippable copy. There is no cloud sync, so export
periodically — clearing site data or deleting the app loses the entries.

## Publishing

Static files, no build step. Push to `main` and turn on GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

Everything is relative-path, so it works fine from a `/repo-name/` subpath.

## Editing it

Everything is in `index.html` — markup, styles, script. To add or change a field:

1. Add the control to the markup with a `data-f="fieldName"` attribute. The binder reads and
   writes any `.scale`, `.chips` (add `one` for single-select), `.stepper`, `input` or `textarea`
   automatically — no wiring needed.
2. Add a column for it in `dailyCSV()` or `attackCSV()`.

After changing `index.html`, bump `CACHE` in `sw.js` — otherwise installed phones keep serving
the cached old version.

Icons are generated by `tools/mkicon.py` (no dependencies): `python3 tools/mkicon.py`.
